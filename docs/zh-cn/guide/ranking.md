# 为网站排名

每个网站都有一个*排名*，你可以通过它的任何结果上的 ⚖ 按钮、工具栏弹出窗口，或**设置 → 你的网站**来选择。

按钮上的天平会随网站的排名倾斜：被降低的网站左侧下沉，被提升的网站上扬，其余的保持水平。被置顶网站的按钮上有一枚金色图钉；被隐藏网站的按钮（显示出来后）上有一只划掉的眼睛。结果上没有单独的“已提升”或“已降低”标签，因为按钮已经显示了它的排名。使结果移动或隐藏的标签会[用标志取代它的菱形](./tags.md)。

菜单中的天平会把所有因素放在一起称量：你的排名、你的标签和你的列表。结果移动得越远，天平倾斜得越多，所以你提升了两次的网站，或带有两个你设为提升的标签的网站，会比只提升一次倾斜得更多。

| 排名 | 该网站的结果会怎样 |
| --- | --- |
| **隐藏** | 它们会消失，或缩成一行可以展开的文字（见下方“已隐藏的结果”一节）。 |
| **降低** | 它们下移五位。再次选择会下移十位，箭头会多出第二个箭头。第三次点击则取消。 |
| **正常** | 取消你自己设定的排名，这样你的标签和列表就会像没有它一样来称量这个网站。 |
| **提升** | 它们上移五位。再次选择会上移十位，箭头会多出第二个箭头。第三次点击则取消。 |
| **置顶** | 它们排到最前面，带一圈细细的金色轮廓（在**设置 → 外观**中选择素色后为灰色）。 |

提升和降低会叠加在称量该网站的其他所有因素之上：你的列表，以及[你设为置顶、提升或降低的标签](./tags.md)。如果某个列表把一个网站降低 3 位，而你提升了它，它就会上移 2 位，而提升它的标签仍保留自己的标志。置顶和隐藏会取代列表的说法。你设为隐藏的标签不会隐藏你自己排过名的网站，所以为一个网站排名，就是保留某个会被隐藏标签隐藏的网站的办法。一旦你为某个网站排过名，**你的列表**就会出现在菜单中它的标签里，并带有你的排名的标志。

在菜单中做出更改后，结果上方的摘要会说明你做了什么（“已隐藏 fandom.com。”），并附带一个**撤销**按钮。撤销会把网站恢复成你打开它的菜单之前的样子，包括标签，即使之后又做了几次更改也是如此。这个按钮会保留到你下一次搜索，或你更改另一个网站为止。

## 覆盖网站的多大范围

排名适用于一个网站及其所有子域名。菜单顶部的名称决定级别：选择 `wikipedia.org` 会覆盖各种语言的维基百科，`en.wikipedia.org` 则只覆盖英文版。最具体的选择优先，所以你可以隐藏 `fandom.com`，同时仍然提升 `minecraft.fandom.com`。

对于任何人都能发布自己网站的服务，如 `github.io` 或 `blogspot.com`，选项只到那个人的网站为止：`someone.github.io` 不会提供整个 `github.io`。如果你之前已经为整个服务排过名，它仍会提供，这样你可以更改它。

## 重新排序

Anubis 会对页面上已有的结果重新排序；它无法获取搜索引擎没有发送的结果。位于第 1 页底部的被提升结果会上移，但只出现在第 3 页的网站需要先[加载更多结果](./more-results.md)。

若要保持搜索引擎的顺序，只使用标签和隐藏功能，请关闭**设置 → 外观 → 重新排序结果**。

## 已隐藏的结果

**设置 → 外观 → 已隐藏的结果**决定已隐藏的结果的外观：

- **移除**（默认）：从页面上消失。结果上方的摘要会统计它们，**显示已隐藏**会把它们找回来。
- **折叠**：一行文字，写明网站名称和被隐藏的原因，并附一个**显示**按钮。连续的已隐藏结果共用一行（“fandom.com 及另外 5 个已被你的列表隐藏”），这一行的**显示**会把它们全部恢复。
- **淡化**：留在原处，显示为淡化的样式。

## 你的网站

**设置 → 你的网站**列出你排过名的每个网站及其标签。你可以在那里更改排名，按名称添加网站，或把整个列表作为文本来编辑。

![设置，你的网站](../../img/options-sites.png)

你的网站会保存为一份采用 [Anubis 列表格式](../../list-format.md)（该页面为英文）的列表，所以你可以[发布它](./publish-a-list.md)，供别人订阅。它保存在浏览器的同步存储中，所以会跟着你到你用同一个浏览器账号登录的其他电脑上（[关于同步的更多信息](./sync.md)）。
