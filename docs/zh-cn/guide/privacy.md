# 隐私与权限

Anubis 没有服务器，也不收集任何数据。它在你的浏览器中读取搜索结果和当前标签页的地址来应用你的选择，从不把它们发送给开发者。

## Anubis 如何使用数据

通过浏览器权限获得的数据只用于 Anubis 的功能：为结果排名和加标签、在弹出窗口中显示当前网站、下载你的列表，以及与你连接的 WebDAV 服务器同步。这些数据从不发送给开发者，也不用于广告。

这种使用符合 Chrome Web Store 用户数据政策，包括其有限使用（Limited Use）要求。

## 存储了什么，存在哪里

- **你的网站、设置、标签选择和订阅：** 存在浏览器的同步存储中，浏览器可能会把它们复制到你的其他电脑上。参见 [在多台电脑间同步](./sync.md)。
- **同步服务器的地址、登录信息和密码短语：** 只存在那个浏览器中，从不进入浏览器同步或同步文件。
- **已下载的列表：** 只存在这台电脑上。

## Anubis 会连接到哪里

只有这些：

- **你订阅的列表**，大约每天一次。Anubis 一开始带有九个托管在 GitHub 上的列表；可以在**设置 → 列表**中关闭。
- **GitHub 上的列表目录**，当你打开**设置 → 列表**时。
- **你正在使用的搜索引擎**，用于 [加载更多结果](./more-results.md)。在 Ecosia 上，这些结果的网站图标来自 Ecosia 的图标服务。
- **你的 WebDAV 服务器**，如果你连接了的话。它会收到你的网站、设置、标签选择和订阅，默认加密。不加密时，服务器运营者可以读取它们。
- **问题跟踪器**，当你选择**报告问题**（预先填好 Anubis 的版本、你的浏览器和搜索引擎）或列表的**建议更改**时。它们在新标签页中打开，在你自己提交之前不会发送任何内容。

托管列表的网站能看到你的 IP 地址和请求了哪个文件，和任何下载一样。不会发送其他任何内容。

## 权限

- **搜索引擎的网站**，用来修改它们的结果页面。
- **本 wiki 的 [订阅页面](../../subscribe.md)**（`bishop-v.github.io`），让订阅链接生效。Anubis 在那里只读取链接的地址。
- **存储**，用于你的网站和设置。
- **打开弹出窗口时的当前标签页**（`activeTab`），用于读取网站的地址。

Anubis 不在其他任何网站上运行。只有在你订阅托管在 GitHub 以外的列表或连接同步服务器时，它才会请求读取另一个网站。在 Firefox 中，Anubis 声明不收集任何必需数据，只在你连接同步服务器时请求浏览活动方面的同意；**断开连接**会撤回同意。
