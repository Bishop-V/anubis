# 隐私与权限

::: warning 翻译
这是 Anubis 隐私政策页面的机器翻译。如果译文与[英文版](../../guide/privacy.md)不一致，以英文版为准。
:::

Anubis 没有由开发者运营的服务器。它在你的浏览器中读取搜索结果和当前标签页的地址，以应用你的选择；它不会把这些浏览数据发送给开发者。你的设置保存在你的浏览器中，除非你连接自己的存储服务器，在浏览器之间同步。

## Anubis 如何使用数据

Anubis 只会把通过浏览器权限获取的信息用于面向用户的功能：把你的排名和标签应用到搜索结果上，在弹出窗口中显示当前网站的设置，下载你订阅的列表，以及同步到你连接的 WebDAV 服务器。它不会把这些信息发送给开发者，也不会把它们用于广告。Anubis 没有自己的同步服务器。

这种使用符合 Chrome 应用商店用户数据政策，包括其中的“有限使用”要求。

## 保存了什么，保存在哪里

- **你的列表、设置、标签选择和订阅**保存在浏览器的同步存储中。如果你已登录浏览器（Firefox 或 Google 账号）并开启了同步，浏览器会把它们复制到你的其他电脑上。Anubis 从不会看到它们。如果你的列表对同步存储来说太大，它只会保留在这台电脑上。参见[在多台电脑间同步](./sync.md)。
- **同步服务器的地址和登录信息**，如果你连接了服务器以便在浏览器之间同步，只保存在那个浏览器中，绝不保存在浏览器同步中。Anubis 会把登录信息发送到该服务器用于登录；它不属于同步文件。如果你启用了端到端加密，它的密码短语也只保存在那个浏览器中，以便自动同步能对文件进行解密和加密。
- **已下载的列表**只保存在这台电脑上，在其他地方会重新下载。

## Anubis 会连接什么

只有这些：

- **你订阅的列表**，连接到它们的托管位置，每天检查一次新版本，列表有要求时则更少（Anubis 自己的列表：每周一次）。这从你安装 Anubis 时开始，因为它会为你订阅托管在其 GitHub 仓库中的七个列表：五个是它自己的，两个是它根据其他项目的数据生成的。你可以在**设置 → 列表**中关闭它们。
- **GitHub 上的列表目录**，在你打开**设置 → 列表**时，以便**更多列表**显示最新的列表。
- **你所在的搜索引擎**，用于[加载更多结果](./more-results.md)，它会像“Next”链接那样加载它的下一页。如果搜索引擎发来一个没有结果的页面，Anubis 会在你看不见的地方再打开该页面一次，这等同于你自己打开它。
- **你为在浏览器之间同步而连接的 WebDAV 服务器**，如果你这样做了。Anubis 会把你排过名的网站、设置、标签选择和订阅发送到你提供的 HTTPS 地址，不会发往其他任何地方。新连接默认开启端到端加密：启用后，服务器收到的是它无法读取的加密文件。你可以在连接时关闭它；已有的未加密连接在你启用之前会保持未加密。没有加密时，服务器运营者可以读取该文件。参见[在浏览器之间](./sync.md)。
- **GitHub 上 Anubis 的问题跟踪器**，在你选择**报告问题**时。这会在新标签页中打开一个新的 issue，其中填好了 Anubis 的版本、你的浏览器及其版本，以及你所在的搜索引擎，而不包含页面本身的任何内容。除非你自己提交 issue，否则不会发送任何内容。
- **问题跟踪器**，在你选择“报告给…”或“推荐给…”时。这会在新标签页中打开一个页面，其中有结果的地址（不含 `?` 之后的任何内容，那里可能带有你这次访问的细节）和匹配的规则；除非你自己提交 issue，否则不会发送任何内容。

下载列表和任何其他下载一样：托管它的网站会看到你的 IP 地址以及请求的是哪个文件。Anubis 不会随之发送其他任何内容：没有 Cookie，没有标识符，也没有任何关于你的搜索的信息。

## 权限

安装 Anubis 时，你的浏览器会请求：

- **访问搜索引擎的网站**，这样 Anubis 才能更改它们的结果页面。
- **访问本 wiki 的[订阅页面](../../subscribe.md)**，这样订阅链接才能打开 Anubis 的设置并填好一个列表。你的浏览器会以本 wiki 所在的网站来称呼它，即 `bishop-v.github.io`。Anubis 在那里只读取链接的地址。
- **存储**，用来保存你的列表和设置。
- **当你打开工具栏弹出窗口时的当前标签页**（称为 `activeTab`）。这让弹出窗口能读取你所在网站的地址，以便你为它排名。它不会在安装时显示警告，并且持续到该标签页转到另一个页面为止。

Anubis 不会在任何其他网站上运行。

在你订阅时，Anubis 还可能请求**读取某个网站**，也就是托管列表的网站。对于托管在 GitHub 或 gist 之外的任何地方的列表，这都是必需的。连接同步服务器时，它也会同样询问。你可以在浏览器的扩展设置中收回这两项权限。

在受支持的 Firefox 版本中，Anubis 声明不需要任何数据收集，并且只在你连接同步服务器时才请求可选的浏览活动同意。随后 Firefox 会询问 Anubis 是否可以把你的列表发送到那里。**断开连接**会收回这项同意。
