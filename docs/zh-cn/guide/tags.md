# 标签

标签是结果标题下方的小标记，例如“Official docs”或“Paywalled”。它们来自你的列表，也来自你自己。

## 自己给网站加标签

- **在任何网站上：** 打开工具栏弹出窗口，点击**标签**下的一个标签，或输入**新标签**。
- **在搜索页面上：** 打开结果的菜单，点击 **+ Tag**。
- **在设置 → 标签中：** 点击标签上的**编辑**，可以重命名、添加或移除网站，并为每个网站写一条说明。

你给网站加的标签以粗体和下划线显示。来自列表的标签会注明列表名；只有该列表能移除它。

要按自己的顺序排列标签，在**设置 → 标签**中拖动圆点，或将焦点放在圆点上并按上下方向键。弹出窗口和结果菜单都按这个顺序显示。

## 决定标签的作用

列表决定哪些网站得到标签。你在**设置 → 标签**中决定标签的作用：

| 选项 | 带有该标签的结果 |
| --- | --- |
| **跟随列表** | 按列表的规定处理（默认）。大多数列表只加标记。 |
| **仅作标签** | 保持原位。 |
| **高亮显示** | 加上淡淡的背景。 |
| **置顶** | 移到最上面。 |
| **提升** / **降低** | 上移或下移五位。 |
| **隐藏** | 被隐藏。 |

关闭**显示**，可以让标签继续起作用而不显示标记。

### 查看标签对结果的作用

移动或隐藏结果的标签，会用图钉、箭头或划掉的眼睛代替它的菱形。

### 一个结果上有多个标签

每个设为提升的标签让结果上移五位，每个设为降低的标签让它下移五位，所以它们会叠加或抵消。设为隐藏的标签总会隐藏结果，除非你自己给该网站排了名。结果菜单中的**原因**会显示合计。

## 标签归谁

列表拥有其标签的名称和颜色，以及它标记的网站。你拥有你的网站。你改的名称和颜色会显示在列表的之上，双方互不覆盖。如果列表不再使用你正在用的某个标签，它会移到**你的标签**中。

## 只显示一个标签

点击结果上方摘要中的一个标签，只显示这些结果。**显示全部**返回。

## 共享标签

使用同一标签 ID（如 `paywall`）的列表共享一个标签。参见 [列表格式](../../list-format.md#tags)（英文）。
