# 标签

标签是结果标题下方的小标记：“Official docs”“Discussion”“Paywalled”。它们来自你订阅的列表和你自己的选择。

## 自己为网站加标签

在任何网站上，打开工具栏中的 Anubis 弹出窗口。在**标签**下，点击一个标签即可把它添加到该网站，再次点击则移除。若要为该网站创建新标签，请在**新标签**中输入名称，然后点击**添加标签**。在搜索页面上，每个结果上的 ⚖ 菜单提供相同的操作。

你自己的标签在**你的标签**下，你的列表所使用的标签在**来自列表的标签**下。你可以把来自列表的标签添加到任何网站，这只会更改你自己的列表，不会改动那个列表。标签超过八个时，其余的会折叠到**显示更多标签**后面；该网站已有的标签始终可见。你给网站加的标签是粗体，并带有它的颜色的下划线。列表给网站加的标签是普通样式，后面跟着列表的名称（“来自 Paywalls”）：只有那个列表能把它去掉，⚖ 菜单中的**有误？报告**会把这个问题告诉列表的维护者。

## 标签归谁所有

一个标签由三部分构成，每一部分都有一个所有者：

| 内容 | 谁来更改 |
| --- | --- |
| 它的 ID，例如 `paywall` | 没有人：使用相同 ID 的列表共用这个标签（见下方“共用标签”一节）。 |
| 它的名称、颜色和描述 | 定义它的列表。你在**设置 → 标签**中重命名或改色会显示在列表的设置之上，并且永远不会被覆盖。 |
| 哪些网站带有它 | 每个列表管自己的网站，你管你的网站。列表的更新绝不会改动你的网站，你的网站也绝不会改动列表。 |

当你把列表的标签添加到你自己的某个网站时，你的列表会保存该标签的名称、颜色和描述的一份副本。在列表仍在定义该标签时，你看到的是列表的版本，所以列表的更新会传达给你。如果列表不再使用该标签，或你取消订阅，你的网站会以同样的名称保留它，它会移到**你的标签**中。

## 查看标签来自哪里

**设置 → 标签**分为两组。**你的标签**是你创建的，或只有你自己的网站使用的标签。**来自列表的标签**是你订阅的列表给网站加的标签，每个标签会说明它来自哪些列表，例如“来自 Paywalls”。你的某个标签如果也被列表使用，会显示“也被以下列表使用”和列表的名称。取消订阅某个列表后，它的标签就会离开第二组。

## 决定标签的作用

列表决定哪些网站得到标签。标签有什么作用则由你在**设置 → 标签**中决定：

| 选择 | 带有该标签的结果会怎样 |
| --- | --- |
| **跟随列表** | 列表怎么说就怎么做（默认）。大多数列表只加标签。 |
| **仅作标签** | 显示标签，绝不改变排名。 |
| **高亮显示** | 给结果加上与标签颜色一致的淡淡背景。 |
| **置顶** | 把结果放到最前面，就像你置顶了它的网站一样。 |
| **提升** / **降低** | 把结果上移或下移五位。 |
| **隐藏** | 隐藏结果，无论是哪个列表加的标签。 |

在每个标签的名称下，有一行文字说明哪些网站带有它，以及它们会怎样，例如“标记了来自 Paywalls 的 23 个网站。仅作标签：这些网站的排名保持不变。”Paywalls 列表只加标签；若要降低有付费墙的网站，请为该标签选择**降低**。

### 查看标签对结果做了什么

在结果下方，每个标签都以一个带有它颜色的菱形开头。当标签使该结果移动或被隐藏时，一枚图钉（置顶它）、向上的箭头（提升它）、向下的箭头（降低它）或划掉的眼睛（隐藏它）会取代菱形。这个标志显示的是你对该标签的选择，或者在你跟随列表时，显示列表所做的事。相同的标志也出现在结果的 ⚖ 菜单和工具栏弹出窗口中。

关闭**显示**，可以让标签继续起作用，同时不在结果下方显示它的标记。点击标签的颜色可以更改它。若要在搜索页面上把所有标签显示为灰色，请在**设置 → 外观 → 搜索页面上的颜色**中选择**素色**。这样标签就靠名称来区分。

## 自己为网站加标签

点击标签旁边的**编辑**即可打开它。在那里你可以：

- 重命名标签，并为你自己的标签写描述；
- 查看带有该标签的你的网站，并点击 × 为其中一个去掉该标签；
- 为更多网站加标签：输入一个网站，或用空格或逗号分隔的多个网站，然后点击**添加网站**。你还可以为这个或这些网站添加一条说明；每条备注都会作为注释与该网站的规则一起保存；
- 查看你的每个列表给这个标签加的前几个网站。

搜索结果上的 ⚖ 按钮会以同样的方式为该结果的网站加标签。

你自己的标签旁边的垃圾桶会删除它，并把它从你的网站上去掉。Anubis 不会先询问：它会说明删除了什么，旁边有**撤销**按钮，持续几秒钟。

### 一个结果上有多个标签

当一个结果带有几个你设为**提升**或**降低**的标签时，Anubis 会把它们放在一起称量：每个提升使它上移五位，每个降低使它下移五位。

| 结果上的标签 | 它去哪里 |
| --- | --- |
| 一个提升 | 上移五位 |
| 三个提升 | 上移十五位 |
| 两个提升和一个降低 | 上移五位，就像只有一个提升 |
| 一个提升和一个降低 | 留在搜索引擎放的位置 |

一个标签只计一次，无论你有多少个列表给它。设为**隐藏**的标签无论其他标签怎么说，仍会隐藏结果。结果 ⚖ 菜单中的**原因**会显示每个标签的作用，以及结果最终在哪里（“为每个“Official docs”和“Reference”标签将其提升 5 位，并为“Paywall”将其降低 5 位，所以它上移 5 位”）。

你自己给网站设的排名会叠加到它的标签上。如果你提升了一个网站，而它带有一个设为降低的标签，两者会相互抵消。设为隐藏的标签不会隐藏你自己排过名的网站，所以你可以保留一个会被该标签隐藏的网站。如果你自己隐藏了一个网站，无论它的标签怎么说，它都保持隐藏。

## 只显示一个标签

结果上方的摘要会列出页面上的标签，以及每个标签有多少个结果。点击其中一个即可只显示这些结果；点击**显示全部**则返回。在手机上，点击摘要中的**详情**即可看到它们。

## 共用标签

标签由一个简短的 ID 标识，例如 `ai-slop`。当两个列表使用相同的 ID 时，你会看到一个由两者共同提供的标签，名称取第一个列表给它的名称。没有什么额外的内容需要订阅：不同作者的列表通过使用相同的 ID 形成共用的词汇；参见[列表格式](../../list-format.md#tags)（英文）。
