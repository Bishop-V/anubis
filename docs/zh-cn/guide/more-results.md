# 加载更多结果

摘要中的**加载更多结果**会把下一页拉到这一页上，并一起排名。后面的结果会标上“来自第 2 页”等。在手机上，它在**详情**中。

## 自动

**设置 → 外观 → 自动加载更多结果**会在每次搜索时多加载最多 20 页。每页大约多花一秒，加载太多可能会触发人机验证。

## 工作原理

Anubis 会向你正在使用的搜索引擎请求下一页，就像它自己的“下一页”链接一样。Startpage、Kagi、Yandex、Mojeek 以及 DuckDuckGo HTML 和 Lite 版尚不支持。

## 何时停止

摘要会说明原因，并附上打开该页面的链接。没有更多结果时，按钮会消失。

## 人机验证

如果搜索引擎想确认你不是机器人，请打开它指出的页面，通过验证，然后再次点击**加载更多结果**。Anubis 从不替你作答。Ecosia 经常要求验证。
