# 加载更多结果

搜索引擎一次只发送一页结果，所以 Anubis 只能对该页面上已有的内容重新排序。结果上方摘要中的**加载更多结果**会把下一页并入当前页面，并把所有结果放在一起排名。你置顶的、只出现在第 3 页的网站，点击两次后就会升到最前面。在手机上，它位于摘要的**详情**下。

来自后面页面的结果，会在标题下方用一个小小的空心标记注明“来自第 2 页”等。它们紧接在最后一个结果之后，所以搜索引擎自己的页码链接仍留在底部。

## 自动加载

**设置 → 外观 → 自动加载更多结果**会在每次搜索中加载你输入的额外页数，从 0（关闭）到 20。默认是关闭的。每个额外页面都是对搜索引擎的又一次请求，会使搜索多花大约一秒。如果请求过多，搜索引擎可能会显示验证码或限速，而且大多数引擎在 20 页之前就不再发送页面。设置里会说明你输入的数量要付出什么代价。它会在搜索引擎自己的“Next”链接或“More results”按钮出现在页面底部之后开始，摘要中的按钮从那时起也会显示。

## 工作原理

- **DuckDuckGo：** Anubis 会点击 DuckDuckGo 自己的“More results”按钮。
- **Google、Bing 和 Yahoo：** Anubis 在后台跟随页面的“Next”链接，并把结果添加到当前页面。
- **Brave Search 和 Ecosia：** Anubis 用页面自己的链接所用的方式请求下一页。

请求只会发送给你所在的搜索引擎，页面逐页加载，每页之间有短暂的停顿。如果搜索引擎发来一个没有结果的页面，通常是因为它想让你确认自己不是机器人，Anubis 会再试一次：它在你看不见的地方打开那个页面，就像你自己打开一样，然后再把它关掉。

## 何时停止

当某个页面没有到来时，摘要会在它的第一行下方说明原因，例如“Bing 没有为第 3 页发送任何结果”，**打开第 3 页**会在新标签页中打开该页面，让你看到搜索引擎发送了什么。如果它要求你确认自己不是机器人，请在那里完成，然后再次点击**加载更多结果**。要求 Anubis 放慢速度的搜索引擎，会在短暂等待后再获得一次尝试。当搜索引擎只发送页面上已有的结果时，说明没有更多了，按钮会消失。Startpage、Kagi、Yandex、Mojeek 以及 DuckDuckGo 的 HTML 版和 Lite 版目前还不支持此功能。
