# 在多台电脑间同步

你的网站、设置、标签选择和订阅会通过浏览器同步。若要在 Firefox 和 Chrome 之间同步，请连接一台 WebDAV 服务器。订阅的列表不会被复制；每个浏览器各自下载。

## 浏览器同步

默认开启，通过你的浏览器账户：

- **Firefox：** 登录，并在 Firefox 设置的**同步**下勾选**附加组件**。
- **Chrome：** 登录并开启同步，保持**扩展程序**在同步内容中。

它只会同步到其他电脑上的同一种浏览器。Android 版 Firefox 不同步附加组件数据。

## 在浏览器之间

在每个浏览器中连接同一个 WebDAV 存储。Anubis 在那里保存一个文件：`anubis-sync.json`。

### 获取地址和密码

你需要服务的 WebDAV 地址、用户名和应用专用密码。

| 服务 | 地址 | 应用专用密码 |
| --- | --- | --- |
| **Koofr**（免费 10 GB） | `https://app.koofr.net/dav/Koofr` | **Preferences → Password → App passwords**。用户名是你的电子邮件地址。 |
| **InfiniCLOUD**（免费 20 GB） | 在账户页面的 **Apps Connection** 下 | 同一页面。 |
| **Nextcloud** | `https://your-server/remote.php/dav/files/your-user-name/` | **设置 → 安全 → 设备和会话**。 |

任何通过 `https://` 提供的 WebDAV 服务器都可以。

### 连接

![设置，同步](../../img/options-sync.png)

1. 在**设置 → 同步 → 在浏览器之间**中，输入地址、用户名和密码。
2. 保持**对同步文件进行端到端加密**开启，并选择至少 12 个字符的密码短语。在每个浏览器中使用同一个。
3. 点击**连接**，并允许浏览器的提示。
4. 在另一个浏览器中重复以上步骤。

文件使用 AES-256-GCM 加密，服务器无法读取。如果你忘了密码短语，服务器上的副本将无法恢复，但每个浏览器都会保留自己的数据。

### 更改密码短语

使用**设置 → 同步**中的**更改加密密码短语**，然后在其他每个浏览器中输入新的密码短语。

### 何时同步

更改后几秒钟、浏览器启动时，以及搜索时（最多每 5 分钟一次）。**立即同步**会马上同步。

### 两个浏览器中的更改

两个浏览器中的更改会被合并。如果两边改了同一项，最后同步的那一边胜出。

### 断开连接

**断开连接**会停止该浏览器中的同步。你的数据会保留，服务器上的文件也会保留。

## 限制

- 浏览器同步大约能容纳 10,000 个网站。超出后，你的网站只保存在那台电脑上；WebDAV 没有这个限制。
- 托管在 GitHub 以外的列表需要在每个浏览器中授权：点击**设置 → 列表**中它的 ↻。
- 若只迁移一次，请 [导出备份](./import-and-backup.md) 再恢复。

## 隐私

浏览器同步通过你的浏览器账户进行。WebDAV 服务器会收到同步文件和你的登录信息。密码短语从不发送。参见 [隐私与权限](./privacy.md)。
