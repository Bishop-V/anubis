# 搜索引擎

可以在**设置 → 搜索引擎**中关闭任意搜索引擎。

| 搜索引擎 | 支持情况 | 加载更多结果 |
| --- | --- | --- |
| Google | 支持 | 是 |
| DuckDuckGo | 支持 | 是 |
| DuckDuckGo HTML 和 Lite | 支持 | 否 |
| Bing | 支持 | 是* |
| Brave Search | 支持 | 是 |
| Startpage | 支持 | 是 |
| Ecosia | 支持 | 是* |
| Kagi | 支持 | 否 |
| Yahoo | 支持 | 是* |
| Yandex | 支持 | 是* |
| Mojeek | 实验性 | 是 |

**支持**的搜索引擎已在真实网站上检查过；**实验性**的还没有。在 Android 版 Firefox 上，Google、DuckDuckGo 和 Bing 可以使用。

\* 这些搜索引擎有时会在下一页之前要求 [人机验证](./more-results.md)。

网页结果在所有地方都会被称量。在大多数搜索引擎上，图片、视频和新闻标签页中的结果会加标签和隐藏，但不重新排序。购物标签页保持原样。

## 如何找到结果

根据它们的形状（一个标题和它的链接），而不是页面的类名，所以小的改版不会造成破坏。在这种方法不奏效的地方，Anubis 使用 [uBlacklist](https://github.com/ublacklist/builtin) 的布局。

## 当某个搜索引擎出问题时

参见 [疑难解答](./troubleshooting.md)。
