# 搜索引擎

Anubis 适用于这些搜索引擎的网页结果。你可以在**设置 → 搜索引擎**中关闭其中任何一个。

| 搜索引擎 | 支持情况 | 加载更多结果 | 在真实网站上检查过 |
| --- | --- | --- | --- |
| Google（每个国家的域名） | 支持 | 是 | 是，结果和清理都检查过。手机版布局还没有。 |
| DuckDuckGo | 支持 | 是 | 是 |
| DuckDuckGo HTML 和 Lite | 支持 | 否 | 是 |
| Bing | 支持 | 是* | 是 |
| Brave Search | 支持 | 是 | 是 |
| Startpage | 支持 | 是 | 是 |
| Ecosia | 支持 | 是* | 是 |
| Kagi | 支持 | 否 | 是 |
| Yahoo | 支持 | 是* | 是 |
| Yandex | 支持 | 是* | 是 |
| Mojeek | 实验性 | 否 | 尚未 |

在支持还处于实验阶段的 Android 版 Firefox 上，Google、DuckDuckGo 和 Bing 会向手机发送它们自己的布局，Anubis 会读取其中每一种。这三个已在手机上试过；其他搜索引擎的手机版布局还没有。

**支持**表示已在真实网站上试过。**实验性**表示它遵循其他工具记录的布局，但尚未在真实网站上试过，所以有些功能可能无法使用。

\* Bing、Ecosia、Yahoo 和 Yandex 有时会用“确认你不是机器人”的检查来回应获取下一页的请求。加载更多结果随后会停下来，也不说明原因。如果发生这种情况，请使用搜索引擎自己的“Next”链接。

主要的网页结果在所有引擎上都会被称量。此外：

- **图片、视频和新闻标签页**在 DuckDuckGo、Bing、Brave Search、Ecosia、Kagi、Startpage 和 Yandex（仅视频）上，以及 Google 的图片和新闻标签页上会被称量。Google 的视频标签页像网页一样列出结果，所以按网页结果来称量。图片和视频会被加标签和隐藏，但不会重新排序，所以网格保持原来的形状。已隐藏的不会留下空缺。这些标签页都还没有在真实网站上检查过。
- **不受影响：** Yahoo 和 Mojeek 的标签页、Yandex 的其他标签页，以及所有购物标签页。

## 如何找到结果

搜索引擎经常改变页面的外观，它们使用的内部名称也会随之变化。在可能的情况下，Anubis 通过结果的形状来找到它们：一个标题、围绕它的链接，以及只包含该结果的最小区块。小幅的改版不会破坏这种方式。

对于标题不是 heading 元素的引擎，Anubis 使用 [uBlacklist](https://github.com/ublacklist/builtin) 项目持续更新的结果布局。

## 搜索引擎出问题时

如果某个引擎上的结果不再有标签或按钮，或摘要出现在错误的位置，请参阅[疑难解答](./troubleshooting.md)。
