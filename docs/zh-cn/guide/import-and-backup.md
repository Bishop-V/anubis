# 从其他工具迁移

## 导入网站

你来自 uBlacklist、HOHSER 或 Brave Goggle？请打开**设置 → 备份 → 导入网站**，粘贴你的规则（或点击**选择文件**），然后点击**导入**。这些网站会并入你自己的列表。

| 来自 | 你会得到 |
| --- | --- |
| **uBlacklist** 规则 | 被屏蔽的网站会被隐藏。取消屏蔽的规则（`@…`）会让网站保持为正常。高亮规则会变成起高亮作用的标签。 |
| **HOHSER** 导出文件 | 隐藏仍是隐藏，部分隐藏变成降低，高亮颜色变成起高亮作用的标签。 |
| **Brave Goggle** | Discard 会被隐藏，boost 会被提升，downrank 会被降低。 |
| **域名列表** | 每个域名都会被隐藏。 |

Anubis 会说明它读到了什么（“已读取为 HOHSER 导出文件：添加了 2 个网站，更新了 0 个。”）。需要网站名称之外更多信息的规则，如路径或 uBlacklist 的标题表达式，会被跳过并计数。

你不必导入别人发布的列表。请改为[订阅它](./lists.md)，这样你就能收到他们的更新。

## 备份

**导出备份**会把所有内容保存到一个文件中：设置、标签选择、订阅和你的列表。**恢复备份**会加载该文件，可以在这个浏览器上，也可以在另一个浏览器上。这也是在 Firefox 和 Chrome 之间迁移一次的办法；若要让它们保持同步，请[连接同步服务器](./sync.md)。**重置设置**会把设置、标签选择和订阅恢复到安装时的样子，并保留你的列表。随后那条消息旁边的**撤销**，可以在几秒钟内把它们找回来。

## 分享你的列表

你自己的列表是一个纯文本文件。**下载我的列表**会保存它，随时可以[发布](./publish-a-list.md)。
