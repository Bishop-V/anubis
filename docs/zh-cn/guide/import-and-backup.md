# 从其他工具迁移

## 导入网站

**设置 → 备份 → 导入网站**接受你的规则：粘贴它们或选择文件，然后点击**导入**。

| 来源 | 结果 |
| --- | --- |
| **uBlacklist** | 被屏蔽的网站会被隐藏；高亮变成标签。 |
| **HOHSER** | 隐藏的仍然隐藏，部分隐藏变成降低，高亮变成标签。 |
| **Brave Goggle** | discard 被隐藏，boost 被提升，downrank 被降低。 |
| **域名列表** | 每个域名都被隐藏。 |

需要网站名称以外信息的规则会被跳过。对于别人发布的列表，请 [订阅](./lists.md) 它，以便获得更新。

## 备份

**导出备份**把所有内容保存到一个文件中，**恢复备份**可以在任何浏览器中加载它。**重置设置**会恢复默认值，但保留你的网站。

## 分享你的列表

**下载我的列表**会把你的网站保存为文本文件，可以直接 [发布](./publish-a-list.md)。
