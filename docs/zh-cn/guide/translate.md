# 帮助翻译

::: warning 机器翻译：请谨慎使用
Anubis 以英文编写，这是它唯一完整支持的语言。它也有**阿拉伯语、孟加拉语、中文（简体）、中文（繁体）、法语、德语、印地语、印度尼西亚语、意大利语、日语、韩语、巴西葡萄牙语、俄语、西班牙语、土耳其语、乌尔都语和越南语**版本，但这些翻译是机器完成的，尚无说这些语言的人检查过。有些词可能有误或不清楚，所以请谨慎使用。当你为网站排名或隐藏网站时，结果菜单中的**原因**和结果上方的摘要会准确说明发生了什么；如果某个译文让你拿不准，请核对英文。若要用英文查看 Anubis，请把浏览器的语言设为英文。
:::

Anubis 的界面是英文的。它显示的每个词都可以翻译：工具栏弹出窗口、设置、欢迎页面，以及它在搜索页面上添加的内容。你的浏览器会选择与自己语言对应的翻译，翻译中遗漏的任何内容仍保持英文。在除英文外的任何语言下，设置、欢迎页面和工具栏弹出窗口都会注明这份翻译出自机器，并附有指向本页面的链接。

这个 wiki 也有简体中文版（机器翻译，尚未经过中文母语者检查），位于仓库的 `docs/zh-cn/` 文件夹中。面向列表发布者和贡献者的技术页面，如列表格式、列表目录、订阅页面和实验记录，仍为英文。

如果你会说其中一种语言，修正它是最有用的第一件事：见下文。

## 如何翻译

翻译是一个文件夹，位于 [Anubis 的仓库](https://github.com/Bishop-V/anubis)中的 `locales/<语言>/`，其中有 `messages.json`（采用浏览器为每个扩展使用的格式）和 `sources.json`（每条消息翻译所依据的英文）。在托管翻译项目启动之前，请以 pull request 的形式提交：

1. 把 `public/_locales/en/messages.json` 复制到 `locales/<语言>/messages.json`，文件夹以你的语言代码命名，地区前加一个下划线：`de`、`fr`、`pt_BR`、`zh_CN`、`zh_TW`。浏览器只会使用[它们认识的代码](https://developer.chrome.com/docs/extensions/reference/api/i18n#locales)。
2. 翻译每个 `message`。你可以省去 `description`；在英文中，描述说明文字出现在哪里，以及每个 `$1` 或 `$2` 代表什么。
3. 把 `langCode` 设为你的语言代码，与文件夹的名称相同。
4. 运行 `node scripts/locales.mjs record <语言>`。它会写入 `sources.json`，这样以后英文发生变化时 Anubis 能够察觉。
5. 提交 pull request。一项检查会确保每个键在英文中都存在，每个占位符都保留了下来，每条消息都说明了它依据的是哪条英文。

你不必一次翻译所有内容：漏掉一条消息，它就会显示为英文。

### 修正机器翻译

修改 `locales/<语言>/messages.json` 中的 `message`，并在 pull request 中说明你会说这种语言。当你通读完整种语言后，请更改上表中的“尚未”。`node scripts/locales.mjs status` 会列出英文在翻译之后发生了变化的消息；请逐条重新翻译，然后对它运行 `node scripts/locales.mjs record <语言> <键>`。

## 需要保留的内容

- **占位符。** `$1`、`$2` 等会被填入网站、数字或名称。请保留每一个，顺序按你的语言需要而定。不是占位符的美元符号要写成 `$$`。
- **计数。** 以 `_one` 和 `_other` 结尾的消息是计数的各种形式：“1 个列表”“2 个列表”。请添加你的语言所用的形式，命名遵循 [Unicode 的复数规则](https://www.unicode.org/cldr/charts/latest/supplemental/language_plural_rules.html)：`_zero`、`_one`、`_two`、`_few`、`_many` 和 `_other`。中文只有 `_other`。
- **名称。** Anubis、搜索引擎、浏览器和其他项目（uBlacklist、HOHSER、Brave Goggles）保留它们的名称。当消息提到某个搜索引擎页面的某个部分，如 Google 的“AI Overview”或“People also ask”时，请使用该搜索引擎在你的语言中显示的名称。
- **排名所用的词。** 在 Anubis 中，网站的排名到处都是隐藏、降低、正常、提升或置顶。请为每一个选定一个词，并始终使用它。对于词较长的语言，请在其中加入软连字符（U+00AD），这样结果菜单中那一排排名就能在该断开的地方断开。

## 保持英文的内容

- **发给列表维护者的报告和推荐。** 当你报告某个列表的错误或向它推荐网站时，Anubis 填好的 issue 是英文的，因为列表的维护者未必读得懂你的语言。
- **列表文件。** 你自己的列表（按 Anubis 创建的样子），以及你订阅的列表，都由它们的作者编写。
- **wiki 的技术页面和商店页面介绍。** 它们另行翻译。

## 检查你的翻译

用你的文件构建 Anubis（`npm run build`；参见 [`DEVELOPMENT.md`](https://github.com/Bishop-V/anubis/blob/main/DEVELOPMENT.md)），并在设为你的语言的浏览器中加载它；`ANUBIS_LANG=<代码> node e2e/run.mjs responsive` 会在手机宽度下检查其中的设置。在 Firefox 中，请在“设置 → 常规 → 语言”下添加你的语言；在 Chrome 中，请在“设置 → 语言”下选择它，或用 `--lang=<代码>` 启动 Chrome。请在窄宽度下查看弹出窗口和设置，因为较长的词可能会把按钮挤到第二行。

阿拉伯语和乌尔都语是从右向左书写的：Anubis 的页面以及它添加到搜索页面上的内容会随之翻转。请同样在窄宽度下检查从右向左书写的语言。
