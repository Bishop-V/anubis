# 简介

Anubis 是一款 Firefox 和 Chrome 扩展，在你平时使用的搜索引擎上整理搜索结果。它会隐藏你不想看到的网站，提升你信任的网站，给结果加上标签让你点开之前就心里有数，并移除 AI 回答和其他面板。

## 功能

- **[直接在结果中为任何网站排名](./ranking.md)**：用任意结果旁的按钮隐藏、降低、提升或置顶一个网站。
- **[标签](./tags.md)**：每个标题下方的“Official docs”或“Paywalled”等标签。由你决定每个标签起什么作用。
- **[人人都能发布的列表](./lists.md)**：订阅为你给网站加标签和排名的列表，包括 Brave Goggles 和 uBlacklist 规则集，也可以[发布你自己的列表](./publish-a-list.md)。
- **[移除面板](./clean-up.md)**：从每次搜索中去掉 AI 回答、视频面板和“相关问题”。
- **[不止一页结果](./more-results.md)**：把后面的页面拉到第一页，一起排名。
- **[同步](./sync.md)**：通过浏览器自带的同步，或借助 WebDAV 服务器在 Firefox 和 Chrome 之间同步。
- **[带上旧列表](./import-and-backup.md)**：从 uBlacklist、HOHSER 或 Brave Goggle 导入。
- **轻松撤销**：结果上方的摘要说明 Anubis 改了什么，**显示已隐藏**可以恢复。

Anubis 适用于 Google、DuckDuckGo、Bing、Brave Search、Startpage、Ecosia、Kagi、Yahoo 和 Yandex，并实验性地支持 Mojeek。参见 [搜索引擎](./search-engines.md)。

## 名字的由来

在埃及神话中，阿努比斯用一根羽毛称量每一颗心。没有通过称量的网站会被隐藏。
