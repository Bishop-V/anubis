# 移除面板

**设置 → 移除面板**会从每个搜索页面上去掉你选择的部分。一开始全部关闭。

<!-- Maintainer: Simplified Chinese translation of docs/guide/clean-up.md. The screenshots are the English ones. -->

![设置，移除面板](../../img/options-cleanup.png)

| 开关 | 移除 |
| --- | --- |
| **AI 回答** | Google 的 AI 概览和 AI 模式、Duck.ai，以及 Bing 和 Brave 的 AI 回答。 |
| **视频面板** | 视频和短视频面板。 |
| **相关问题** | 可展开的问题列表。 |
| **讨论面板** | 论坛面板。论坛结果保留。 |
| **头条新闻** | 新闻面板。 |
| **图片行** | 成排的图片。 |
| **相关搜索** | “相关搜索”和“其他人还搜索了”。 |
| **其他搜索引擎** | 在别处重复你的搜索的按钮。 |
| **Ads** | 赞助结果和商品轮播。 |
| **允许广告的请求** | 请你允许广告的横幅。 |

## 移除了什么

摘要会说明移除了什么。**显示已隐藏**会把它们带回来，并加上轮廓。

![清理之后的摘要](../../img/cleanup-summary.png)

## 如何找到面板

根据它们的标题，支持英语、法语、德语、西班牙语、葡萄牙语、意大利语和荷兰语。如果你的语言中某个面板没有被移除，请附上它的标题 [提交 issue](https://github.com/Bishop-V/anubis/issues)。

## 从源头阻止 AI 回答

在 Google 上，**始终打开“网页”标签页**会打开 Google 的纯链接列表，没有 AI，也没有面板。在结果上方选择**全部**可以看到平常的页面。
