# 簡介

Anubis 是一款 Firefox 和 Chrome 擴充功能，在你平時使用的搜尋引擎上整理搜尋結果。它會隱藏你不想看到的網站，提升你信任的網站，給結果加上標籤讓你點開之前就心裡有數，並移除 AI 回答和其他面板。

## 功能

- **[直接在結果中為任何網站排名](./ranking.md)**：用任意結果旁的按鈕隱藏、降低、提升或釘選一個網站。
- **[標籤](./tags.md)**：每個標題下方的“Official docs”或“Paywalled”等標籤。由你決定每個標籤起什麼作用。
- **[人人都能發布的清單](./lists.md)**：訂閱為你給網站加標籤和排名的清單，包括 Brave Goggles 和 uBlacklist 規則集，也可以[發布你自己的清單](./publish-a-list.md)。
- **[移除面板](./clean-up.md)**：從每次搜尋中去掉 AI 回答、影片面板和“相關問題”。
- **[不止一頁結果](./more-results.md)**：把後面的頁面拉到第一頁，一起排名。
- **[同步](./sync.md)**：透過瀏覽器自帶的同步，或藉助 WebDAV 伺服器在 Firefox 和 Chrome 之間同步。
- **[帶上舊清單](./import-and-backup.md)**：從 uBlacklist、HOHSER 或 Brave Goggle 匯入。
- **輕鬆復原**：結果上方的摘要說明 Anubis 改了什麼，**顯示已隱藏**可以恢復。

Anubis 適用於 Google、DuckDuckGo、Bing、Brave Search、Startpage、Ecosia、Kagi、Yahoo 和 Yandex，並實驗性地支援 Mojeek。參見 [搜尋引擎](./search-engines.md)。

## 名字的由來

在埃及神話中，阿努比斯用一根羽毛稱量每一顆心。沒有通過稱量的網站會被隱藏。
