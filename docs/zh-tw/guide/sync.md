# 在多臺電腦間同步

你的網站、設定、標籤選擇和訂閱會透過瀏覽器同步。若要在 Firefox 和 Chrome 之間同步，請連線一臺 WebDAV 伺服器。訂閱的清單不會被複制；每個瀏覽器各自下載。

## 瀏覽器同步

預設開啟，透過你的瀏覽器賬戶：

- **Firefox：** 登入，並在 Firefox 設定的**同步**下勾選**附加元件**。
- **Chrome：** 登入並開啟同步，保持**擴充套件程式**在同步內容中。

它只會同步到其他電腦上的同一種瀏覽器。Android 版 Firefox 不同步附加元件資料。

## 在瀏覽器之間

在每個瀏覽器中連線同一個 WebDAV 儲存。Anubis 在那裡儲存一個檔案：`anubis-sync.json`。

### 獲取地址和密碼

你需要服務的 WebDAV 地址、使用者名稱和應用專用密碼。

| 服務 | 地址 | 應用專用密碼 |
| --- | --- | --- |
| **Koofr**（免費 10 GB） | `https://app.koofr.net/dav/Koofr` | **Preferences → Password → App passwords**。使用者名稱是你的電子郵件地址。 |
| **InfiniCLOUD**（免費 20 GB） | 在賬戶頁面的 **Apps Connection** 下 | 同一頁面。 |
| **Nextcloud** | `https://your-server/remote.php/dav/files/your-user-name/` | **設定 → 安全 → 裝置和會話**。 |

任何透過 `https://` 提供的 WebDAV 伺服器都可以。

### 連線

![設定，同步](../../img/options-sync.png)

1. 在**設定 → 同步 → 在瀏覽器之間**中，輸入地址、使用者名稱和密碼。
2. 保持**對同步檔案進行端到端加密**開啟，並選擇至少 12 個字元的密碼短語。在每個瀏覽器中使用同一個。
3. 點選**連接**，並允許瀏覽器的提示。
4. 在另一個瀏覽器中重複以上步驟。

檔案使用 AES-256-GCM 加密，伺服器無法讀取。如果你忘了密碼短語，伺服器上的副本將無法恢復，但每個瀏覽器都會保留自己的資料。

### 更改密碼短語

使用**設定 → 同步**中的**更改加密密碼短語**，然後在其他每個瀏覽器中輸入新的密碼短語。

### 何時同步

更改後幾秒鐘、瀏覽器啟動時，以及搜尋時（最多每 5 分鐘一次）。**立即同步**會馬上同步。

### 兩個瀏覽器中的更改

兩個瀏覽器中的更改會被合併。如果兩邊改了同一項，最後同步的那一邊勝出。

### 斷開連線

**斷開連接**會停止該瀏覽器中的同步。你的資料會保留，伺服器上的檔案也會保留。

## 限制

- 瀏覽器同步大約能容納 10,000 個網站。超出後，你的網站只儲存在那臺電腦上；WebDAV 沒有這個限制。
- 託管在 GitHub 以外的清單需要在每個瀏覽器中授權：點選**設定 → 清單**中它的 ↻。
- 若只遷移一次，請 [匯出備份](./import-and-backup.md) 再恢復。

## 隱私

瀏覽器同步透過你的瀏覽器賬戶進行。WebDAV 伺服器會收到同步檔案和你的登入資訊。密碼短語從不傳送。參見 [隱私與許可權](./privacy.md)。
