# 在多臺電腦間同步

Anubis 沒有自己的賬號或伺服器。它把你的內容儲存在瀏覽器的同步儲存中，由瀏覽器複製到你的其他電腦上。若要在 Firefox 和 Chrome 之間也能共享，你可以連接自己的儲存服務。

## 同步的內容

- **你的清單**：你排過名或加過標籤的每個網站
- **設定**
- **標籤選擇**：每個標籤的作用，以及它的名稱和顏色
- **訂閱**：你訂閱了哪些清單

你訂閱的清單本身不會在電腦之間複製。每臺電腦會從同一個地址下載自己的副本。

## 瀏覽器同步

這一功能預設就是開啟的，在 Anubis 中無需任何設定。不過，Anubis 無法得知你瀏覽器的同步是否已開啟。如果某項更改沒有出現在你的另一臺電腦上，請在兩臺電腦上都檢查這些設定。

- **Firefox：** 用你的 Mozilla 賬號登入 Firefox。在 Firefox 的設定中，**同步**下，確保勾選了**附加元件**：這也會同步附加元件的資料。Firefox 大約每 10 分鐘同步一次。若要立即同步，請在同一位置選擇**立即同步**。
- **Chrome：** 登入 Chrome 並開啟同步，同時讓**擴充功能**保留在它同步的內容中（Chrome 的設定，**你和 Google** 下）。

瀏覽器同步只能到達你其他電腦上的同一種瀏覽器。Firefox 和 Chrome 之間不互相同步，Android 版 Firefox 則完全不同步附加元件的資料。

## 在瀏覽器之間

若要在 Firefox 和 Chrome 之間，或與 Android 版 Firefox 共享，請在每個瀏覽器中連接同一個儲存。這是可選的，在你連接之前什麼都不會改變。Anubis 可用於任何提供 **WebDAV** 的儲存服務，這是應用在那裡儲存檔案的一種標準方式。它會在那裡保留一個檔案，`anubis-sync.json`。

### 獲取地址和密碼

你需要從服務中得到三樣東西：它的 WebDAV 地址、你的使用者名稱，以及一個應用專用密碼。大多數服務在這裡不接受你平常的密碼。它們會讓你為每個應用另建一個密碼，你可以收回它，而無需更改自己的密碼。

| 服務 | 地址 | 密碼 |
| --- | --- | --- |
| **Koofr**（免費 10 GB） | `https://app.koofr.net/dav/Koofr` | 在 Koofr 中，**Preferences → Password → App passwords**：建立一個。你的使用者名稱是你的電子郵件地址。 |
| **InfiniCLOUD**（免費 20 GB） | 開啟後，顯示在你的賬號頁面的 **Apps Connection** 下 | 同一頁面會顯示應用專用的使用者名稱和密碼。 |
| **Nextcloud** | `https://your-server/remote.php/dav/files/your-user-name/` | **Settings → Security → Devices & sessions**：建立一個應用密碼。 |

其他服務和你自己的伺服器也可以，只要它們提供基於 `https://` 的 WebDAV。任何資料夾都可以：給出它的地址，Anubis 就會把檔案放在那裡。以 `.json` 結尾的地址會被直接當作檔案本身使用。

### 連接

![設定，同步](../../img/options-sync.png)

1. 開啟**設定 → 同步**，在**在瀏覽器之間**下輸入地址、你的使用者名稱和密碼。
2. 保持**對同步檔案進行端到端加密**開啟，並選擇一個至少 12 個字元、長而獨一無二的密碼短語。在每個瀏覽器中使用相同的密碼短語。Anubis 會把它儲存在該瀏覽器的本地擴充功能儲存中，以便後臺同步能夠執行；它絕不會被髮送到伺服器，也不會被瀏覽器同步複製。不要使用你的 WebDAV 登入密碼。
3. 點選**連接**。瀏覽器會詢問是否允許 Anubis 存取該伺服器。Firefox 還會詢問 Anubis 是否可以把你的清單傳送到那裡。
4. 在你的另一個瀏覽器中，用相同的加密密碼短語做同樣的操作。

之後，**設定 → 同步**會顯示 Anubis 上次同步的時間，或出了什麼問題。**立即同步**會立刻同步。

### 為什麼採用這種加密

Anubis 使用 **AES-256-GCM**，這是一種得到廣泛支援的認證加密模式，內建於瀏覽器的 Web Crypto API 中。AES 對同步檔案加密；GCM 還會檢查密文是否被改動，並且每次寫入都使用新的隨機 nonce。256 位的金鑰是用 **PBKDF2-SHA-256** 和一個隨機鹽值，由你的密碼短語派生出來的，所以 Anubis 不會傳送或儲存單獨的金鑰檔案。使用瀏覽器內建的加密功能，避免了附帶第三方加密庫。

這保護的是檔案的內容，而不是你連接伺服器這一事實。伺服器運營者仍然可以看到連接的後設資料，也可以刪除或替換檔案；加密無法阻止對方扣留或重放較舊的加密副本。如果你忘記了密碼短語，伺服器上的副本將無法還原；你在每個瀏覽器中的資料仍然可用。請選擇一個長而獨一無二的密碼短語，並另外保留一份備份。

Anubis 會把密碼短語儲存在該瀏覽器的本地擴充功能儲存中，以便自動同步。它無法抵禦能存取你的瀏覽器配置檔案或以你的身份執行代碼的人。WebDAV 憑據也會儲存在本地，併傳送到伺服器用於登入。

### 更改密碼短語

在**設定 → 同步**中，使用**更改加密密碼短語**。輸入並確認一個至少 12 個字元的新密碼短語。Anubis 會先檢查目前的密碼短語能否解密伺服器上的檔案，然後只有在伺服器確認期間沒有人改動過它時，才會替換它。如果這項檢查或寫入失敗，Anubis 會保留目前的密碼短語，並且不會覆蓋檔案。如果檔案在操作期間發生了變化，請先同步，再重試。

如果伺服器儲存新檔案時連接斷開，Anubis 會把檔案讀回來。當新的密碼短語能開啟它時，Anubis 就儲存新的密碼短語。當 Anubis 無法連接伺服器進行檢查時，它會保留舊的密碼短語並告訴你。如果下一次同步隨後報告密碼短語錯誤，請輸入新的密碼短語。

更改成功後，請在同步之前，在其他每個瀏覽器中輸入新的密碼短語。仍在使用舊密碼短語的瀏覽器無法讀取或更改加密檔案；它會報告密碼短語錯誤，並且不會動該檔案。

新建的連接預設使用加密。若要關閉，請在連接時取消勾選該選項；這樣伺服器運營者就能讀取該檔案。已有的連接在你於“設定 → 同步”中輸入並確認密碼短語並選擇**儲存密碼短語並同步**之前，會保持不加密。加密的檔案要求每個瀏覽器都有密碼短語；如果缺少或錯誤，Anubis 不會覆蓋它。從設定中匯出的普通備份不會被這項功能加密。

### 何時同步

- 你更改某些內容幾秒鐘之後
- 瀏覽器啟動時
- 你搜尋時，最多每 5 分鐘一次

### 來自兩個瀏覽器的更改

Anubis 會合並每個瀏覽器的更改，所以同時使用兩個瀏覽器時不會丟失任何內容：

- 你在 Firefox 中隱藏的網站和在 Chrome 中加了標籤的網站，都會保留。
- 如果你在一個瀏覽器中提升了某個網站，又在另一個瀏覽器中為它加了標籤，它最終會既被提升又帶有標籤。
- 如果兩個瀏覽器在同步之前更改了同一項內容，比如同一個網站的排名或同一項設定，則最後同步的瀏覽器勝出。

瀏覽器第一次連接時，會從檔案中獲取所有內容。你在該瀏覽器中連接之前更改過的網站和設定也會保留，除非檔案更改的正是這些專案。

### 斷開連接

**設定 → 同步**中的**斷開連接**會停止該瀏覽器中的同步。你的清單和設定會留在瀏覽器中，檔案會留在伺服器上。如果想刪除它，請在伺服器上刪除該檔案。

## 限制

- **大小：** 瀏覽器同步為每個附加元件提供約 100 KB 的空間。Anubis 在儲存前會壓縮你的清單，所以大約能容納 10,000 個網站。**設定 → 同步**會顯示它們佔了多少空間。如果你的清單超出了這個範圍，瀏覽器同步只會把它保留在那臺電腦上，設定中也會這樣說明；設定、標籤選擇和訂閱仍會同步。透過伺服器同步沒有這樣的限制。
- **來自其他主機的清單：** 如果你訂閱了不在 GitHub 上的清單，每個瀏覽器都會請求下載它的許可權。同步之後，請在另一個瀏覽器的**設定 → 清單**中點選該清單的**立即更新**按鈕（↻），以便在那裡允許。
- **只遷移一次：** 你也可以[匯出備份](./import-and-backup.md)，然後在另一個瀏覽器中還原。同步檔案的格式相同，所以**還原備份**也能讀取它。

## 隱私

瀏覽器同步透過你的瀏覽器賬號進行，就像你的書籤一樣。Anubis 從不會看到它。

當你連接伺服器時，你的清單、設定、標籤選擇和訂閱只會傳送到該伺服器，而不會發往其他任何地方。啟用端到端加密後，伺服器無法讀取同步檔案；不啟用時，伺服器運營者可以讀取。你的 WebDAV 使用者名稱和密碼會儲存在該瀏覽器中，傳送到伺服器用於登入，並且絕不會放入瀏覽器同步或同步檔案。加密密碼短語會儲存在你設定它的每個瀏覽器的本地，並且絕不會傳送到伺服器。參見[隱私與許可權](./privacy.md)。
