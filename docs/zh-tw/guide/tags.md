# 標籤

標籤是結果標題下方的小標記：“Official docs”“Discussion”“Paywalled”。它們來自你訂閱的清單和你自己的選擇。

## 自己為網站加標籤

在任何網站上，開啟工具列中的 Anubis 彈出視窗。在**標籤**下，點選一個標籤即可把它新增到該網站，再次點選則移除。若要為該網站建立新標籤，請在**新標籤**中輸入名稱，然後點選**新增標籤**。在搜尋頁面上，每個結果上的 ⚖ 選單提供相同的操作。

你自己的標籤在**你的標籤**下，你的清單所使用的標籤在**來自清單的標籤**下。你可以把來自清單的標籤新增到任何網站，這隻會更改你自己的清單，不會改動那個清單。標籤超過八個時，其餘的會摺疊到**顯示更多標籤**後面；該網站已有的標籤始終可見。你給網站加的標籤是粗體，並帶有它的顏色的底線。清單給網站加的標籤是普通樣式，後面跟著清單的名稱（“來自 Paywalls”）：只有那個清單能把它去掉，⚖ 選單中的**有誤？報告**會把這個問題告訴清單的維護者。

## 標籤歸誰所有

一個標籤由三部分構成，每一部分都有一個所有者：

| 內容 | 誰來更改 |
| --- | --- |
| 它的 ID，例如 `paywall` | 沒有人：使用相同 ID 的清單共用這個標籤（見下方“共用標籤”一節）。 |
| 它的名稱、顏色和描述 | 定義它的清單。你在**設定 → 標籤**中重新命名或改色會顯示在清單的設定之上，並且永遠不會被覆蓋。 |
| 哪些網站帶有它 | 每個清單管自己的網站，你管你的網站。清單的更新絕不會改動你的網站，你的網站也絕不會改動清單。 |

當你把清單的標籤新增到你自己的某個網站時，你的清單會儲存該標籤的名稱、顏色和描述的一份副本。在清單仍在定義該標籤時，你看到的是清單的版本，所以清單的更新會傳達給你。如果清單不再使用該標籤，或你取消訂閱，你的網站會以同樣的名稱保留它，它會移到**你的標籤**中。

## 檢視標籤來自哪裡

**設定 → 標籤**分為兩組。**你的標籤**是你建立的，或只有你自己的網站使用的標籤。**來自清單的標籤**是你訂閱的清單給網站加的標籤，每個標籤會說明它來自哪些清單，例如“來自 Paywalls”。你的某個標籤如果也被清單使用，會顯示“也被以下清單使用”和清單的名稱。取消訂閱某個清單後，它的標籤就會離開第二組。

## 決定標籤的作用

清單決定哪些網站得到標籤。標籤有什麼作用則由你在**設定 → 標籤**中決定：

| 選擇 | 帶有該標籤的結果會怎樣 |
| --- | --- |
| **跟隨清單** | 清單怎麼說就怎麼做（預設）。大多數清單只加標籤。 |
| **僅作標籤** | 顯示標籤，絕不改變排名。 |
| **醒目標示** | 給結果加上與標籤顏色一致的淡淡背景。 |
| **釘選** | 把結果放到最前面，就像你釘選了它的網站一樣。 |
| **提升** / **降低** | 把結果上移或下移五位。 |
| **隱藏** | 隱藏結果，無論是哪個清單加的標籤。 |

在每個標籤的名稱下，有一行文字說明哪些網站帶有它，以及它們會怎樣，例如“標記了來自 Paywalls 的 23 個網站。僅作標籤：這些網站的排名保持不變。”Paywalls 清單只加標籤；若要降低有付費牆的網站，請為該標籤選擇**降低**。

### 檢視標籤對結果做了什麼

在結果下方，每個標籤都以一個帶有它顏色的菱形開頭。當標籤使該結果移動或被隱藏時，一枚圖釘（釘選它）、向上的箭頭（提升它）、向下的箭頭（降低它）或劃掉的眼睛（隱藏它）會取代菱形。這個標誌顯示的是你對該標籤的選擇，或者在你跟隨清單時，顯示清單所做的事。相同的標誌也出現在結果的 ⚖ 選單和工具列彈出視窗中。

關閉**顯示**，可以讓標籤繼續起作用，同時不在結果下方顯示它的標記。點選標籤的顏色可以更改它。若要在搜尋頁面上把所有標籤顯示為灰色，請在**設定 → 外觀 → 搜尋頁面上的顏色**中選擇**素色**。這樣標籤就靠名稱來區分。

## 自己為網站加標籤

點選標籤旁邊的**編輯**即可開啟它。在那裡你可以：

- 重新命名標籤，併為你自己的標籤寫描述；
- 檢視帶有該標籤的你的網站，並點選 × 為其中一個去掉該標籤；
- 為更多網站加標籤：輸入一個網站，或用空格或逗號分隔的多個網站，然後點選**新增網站**。你還可以為這個或這些網站新增一條說明；每條備註都會作為註釋與該網站的規則一起儲存；
- 檢視你的每個清單給這個標籤加的前幾個網站。

搜尋結果上的 ⚖ 按鈕會以同樣的方式為該結果的網站加標籤。

你自己的標籤旁邊的垃圾桶會刪除它，並把它從你的網站上去掉。Anubis 不會先詢問：它會說明刪除了什麼，旁邊有**復原**按鈕，持續幾秒鐘。

### 一個結果上有多個標籤

當一個結果帶有幾個你設為**提升**或**降低**的標籤時，Anubis 會把它們放在一起稱量：每個提升使它上移五位，每個降低使它下移五位。

| 結果上的標籤 | 它去哪裡 |
| --- | --- |
| 一個提升 | 上移五位 |
| 三個提升 | 上移十五位 |
| 兩個提升和一個降低 | 上移五位，就像只有一個提升 |
| 一個提升和一個降低 | 留在搜尋引擎放的位置 |

一個標籤只計一次，無論你有多少個清單給它。設為**隱藏**的標籤無論其他標籤怎麼說，仍會隱藏結果。結果 ⚖ 選單中的**原因**會顯示每個標籤的作用，以及結果最終在哪裡（“為每個“Official docs”和“Reference”標籤將其提升 5 位，併為“Paywall”將其降低 5 位，所以它上移 5 位”）。

你自己給網站設的排名會疊加到它的標籤上。如果你提升了一個網站，而它帶有一個設為降低的標籤，兩者會相互抵消。設為隱藏的標籤不會隱藏你自己排過名的網站，所以你可以保留一個會被該標籤隱藏的網站。如果你自己隱藏了一個網站，無論它的標籤怎麼說，它都保持隱藏。

## 只顯示一個標籤

結果上方的摘要會列出頁面上的標籤，以及每個標籤有多少個結果。點選其中一個即可只顯示這些結果；點選**顯示全部**則返回。在手機上，點選摘要中的**詳情**即可看到它們。

## 共用標籤

標籤由一個簡短的 ID 標識，例如 `ai-slop`。當兩個清單使用相同的 ID 時，你會看到一個由兩者共同提供的標籤，名稱取第一個清單給它的名稱。沒有什麼額外的內容需要訂閱：不同作者的清單透過使用相同的 ID 形成共用的詞彙；參見[清單格式](../../list-format.md#tags)（英文）。
