# 從其他工具遷移

## 匯入網站

**設定 → 備份 → 匯入網站**接受你的規則：貼上它們或選擇檔案，然後點選**匯入**。

| 來源 | 結果 |
| --- | --- |
| **uBlacklist** | 被遮蔽的網站會被隱藏；高亮變成標籤。 |
| **HOHSER** | 隱藏的仍然隱藏，部分隱藏變成降低，高亮變成標籤。 |
| **Brave Goggle** | discard 被隱藏，boost 被提升，downrank 被降低。 |
| **域名清單** | 每個域名都被隱藏。 |

需要網站名稱以外資訊的規則會被跳過。對於別人釋出的清單，請 [訂閱](./lists.md) 它，以便獲得更新。

## 備份

**匯出備份**把所有內容儲存到一個檔案中，**還原備份**可以在任何瀏覽器中載入它。**重設設定**會恢復預設值，但保留你的網站。

## 分享你的清單

**下載我的清單**會把你的網站儲存為文字檔案，可以直接 [釋出](./publish-a-list.md)。
