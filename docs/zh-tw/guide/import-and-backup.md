# 從其他工具遷移

## 匯入網站

你來自 uBlacklist、HOHSER 或 Brave Goggle？請開啟**設定 → 備份 → 匯入網站**，貼上你的規則（或點選**選擇檔案**），然後點選**匯入**。這些網站會併入你自己的清單。

| 來自 | 你會得到 |
| --- | --- |
| **uBlacklist** 規則 | 被遮蔽的網站會被隱藏。取消遮蔽的規則（`@…`）會讓網站保持為正常。醒目標示規則會變成起醒目標示作用的標籤。 |
| **HOHSER** 匯出檔案 | 隱藏仍是隱藏，部分隱藏變成降低，醒目標示顏色變成起醒目標示作用的標籤。 |
| **Brave Goggle** | Discard 會被隱藏，boost 會被提升，downrank 會被降低。 |
| **網域清單** | 每個網域都會被隱藏。 |

Anubis 會說明它讀到了什麼（“已讀取為 HOHSER 匯出檔案：新增了 2 個網站，更新了 0 個。”）。需要網站名稱之外更多資訊的規則，如路徑或 uBlacklist 的標題表示式，會被跳過並計數。

你不必匯入別人發布的清單。請改為[訂閱它](./lists.md)，這樣你就能收到他們的更新。

## 備份

**匯出備份**會把所有內容儲存到一個檔案中：設定、標籤選擇、訂閱和你的清單。**還原備份**會載入該檔案，可以在這個瀏覽器上，也可以在另一個瀏覽器上。這也是在 Firefox 和 Chrome 之間遷移一次的辦法；若要讓它們保持同步，請[連接同步伺服器](./sync.md)。**重設設定**會把設定、標籤選擇和訂閱還原到安裝時的樣子，並保留你的清單。隨後那條訊息旁邊的**復原**，可以在幾秒鐘內把它們找回來。

## 分享你的清單

你自己的清單是一個純文字檔案。**下載我的清單**會儲存它，隨時可以[發布](./publish-a-list.md)。
