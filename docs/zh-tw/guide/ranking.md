# 為網站排名

每個網站都有一個*排名*，你可以透過它的任何結果上的刻度盤、工具列彈出視窗，或**設定 → 你的網站**來選擇。

在電腦上，每個結果都有一個刻度盤：網站圖示周圍的一個半圓，左側有一頂小皇冠。點選皇冠即可開啟結果的選單。半圓會從中間開始，隨網站的排名填充：被提升的網站向上填充，被降低的網站向下填充，網站移動的位數越多，填充得越遠；被釘選的網站則填滿一整圈。正常或被隱藏的網站，半圓保持空白。如果結果沒有網站圖示，刻度盤會圍繞一個純灰色的圓形。在圖片和影片結果上，刻度盤是圖片右上角的一個深色小角標，帶有同樣的皇冠，以及一條以同樣方式填充的垂直線。在手機上，結果標題的末尾則是一個 ⚖ 按鈕，它的天平會隨排名傾斜。結果上沒有單獨的“已提升”或“已降低”標籤，因為刻度盤已經顯示了它的排名。使結果移動或隱藏的標籤會[用標誌取代它的菱形](./tags.md)。

選單中的天平會把所有因素放在一起稱量：你的排名、你的標籤和你的清單。結果移動得越遠，天平傾斜得越多，所以你提升了兩次的網站，或帶有兩個你設為提升的標籤的網站，會比只提升一次傾斜得更多。

| 排名 | 該網站的結果會怎樣 |
| --- | --- |
| **隱藏** | 它們會消失，或縮成一行可以展開的文字（見下方“已隱藏的結果”一節）。 |
| **降低** | 它們下移五位。再次選擇會下移十位，箭頭會多出第二個箭頭。第三次點選則取消。 |
| **正常** | 取消你自己設定的排名，這樣你的標籤和清單就會像沒有它一樣來稱量這個網站。 |
| **提升** | 它們上移五位。再次選擇會上移十位，箭頭會多出第二個箭頭。第三次點選則取消。 |
| **釘選** | 它們排到最前面，帶一圈細細的灰色邊框。 |

提升和降低會疊加在稱量該網站的其他所有因素之上：你的清單，以及[你設為釘選、提升或降低的標籤](./tags.md)。如果某個清單把一個網站降低 3 位，而你提升了它，它就會上移 2 位，而提升它的標籤仍保留自己的標誌。釘選和隱藏會取代清單的說法。你設為隱藏的標籤不會隱藏你自己排過名的網站，所以為一個網站排名，就是保留某個會被隱藏標籤隱藏的網站的辦法。一旦你為某個網站排過名，**你的清單**就會出現在選單中它的標籤裡，並帶有你的排名的標誌。

在選單中做出更改後，結果上方的摘要會說明你做了什麼（“已隱藏 fandom.com。”），並附帶一個**復原**按鈕。復原會把網站還原成你開啟它的選單之前的樣子，包括標籤，即使之後又做了幾次更改也是如此。這個按鈕會保留到你下一次搜尋，或你更改另一個網站為止。

## 覆蓋網站的多大範圍

排名適用於一個網站及其所有子網域。選單頂部的名稱決定級別：選擇 `wikipedia.org` 會覆蓋各種語言的維基百科，`en.wikipedia.org` 則只覆蓋英文版。最具體的選擇優先，所以你可以隱藏 `fandom.com`，同時仍然提升 `minecraft.fandom.com`。

對於任何人都能發布自己網站的服務，如 `github.io` 或 `blogspot.com`，選項只到那個人的網站為止：`someone.github.io` 不會提供整個 `github.io`。如果你之前已經為整個服務排過名，它仍會提供，這樣你可以更改它。

## 重新排序

Anubis 會對頁面上已有的結果重新排序；它無法獲取搜尋引擎沒有傳送的結果。位於第 1 頁底部的被提升結果會上移，但只出現在第 3 頁的網站需要先[載入更多結果](./more-results.md)。

若要保持搜尋引擎的順序，只使用標籤和隱藏功能，請關閉**設定 → 外觀 → 重新排序結果**。

## 已隱藏的結果

**設定 → 外觀 → 已隱藏的結果**決定已隱藏的結果的外觀：

- **移除**（預設）：從頁面上消失。結果上方的摘要會統計它們，**顯示已隱藏**會把它們找回來。
- **摺疊**：一行文字，寫明網站名稱和被隱藏的原因，並附一個**顯示**按鈕。連續的已隱藏結果共用一行（“fandom.com 及另外 5 個已被你的清單隱藏”），這一行的**顯示**會把它們全部還原。
- **淡化**：留在原處，顯示為淡化的樣式。

## 你的網站

**設定 → 你的網站**列出你排過名的每個網站及其標籤。你可以在那裡更改排名，按名稱新增網站，或把整個清單作為文字來編輯。

![設定，你的網站](../../img/options-sites.png)

你的網站會儲存為一份採用 [Anubis 清單格式](../../list-format.md)（該頁面為英文）的清單，所以你可以[發布它](./publish-a-list.md)，供別人訂閱。它儲存在瀏覽器的同步儲存中，所以會跟著你到你用同一個瀏覽器賬號登入的其他電腦上（[關於同步的更多資訊](./sync.md)）。
