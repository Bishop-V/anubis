# 移除面板

**設定 → 移除面板**會從每個搜尋頁面上去掉你選擇的部分。一開始全部關閉。每組的開關會同時開啟或關閉組內所有項目；點按組名可逐項選擇。

<!-- Maintainer: Traditional Chinese translation of docs/guide/clean-up.md. The screenshots are the English ones. -->

![設定，移除面板](../../img/options-cleanup.png)

| 開關 | 移除 |
| --- | --- |
| **AI 回答** | Google 的 AI 概覽和 AI 模式、Duck.ai，以及 Bing 和 Brave 的 AI 回答。 |
| **影片面板** | 影片和短影片面板。 |
| **相關問題** | 可展開的問題清單。 |
| **討論面板** | 論壇面板。論壇結果保留。 |
| **焦點新聞** | 新聞面板。 |
| **圖片行** | 成排的圖片。 |
| **相關搜尋** | “相關搜尋”和“其他人還搜尋了”。 |
| **其他搜尋引擎** | 在別處重複你的搜尋的按鈕。 |
| **Ads** | 贊助結果和商品輪播。 |
| **允許廣告的請求** | 請你允許廣告的橫幅。 |

## 移除了什麼

摘要會說明移除了什麼。**顯示已隱藏**會把它們帶回來，並加上輪廓。

![清理之後的摘要](../../img/cleanup-summary.png)

## 如何找到面板

根據它們的標題，支援英語、法語、德語、西班牙語、葡萄牙語、義大利語和荷蘭語。如果你的語言中某個面板沒有被移除，請附上它的標題 [提交 issue](https://github.com/Bishop-V/anubis/issues)。

## 從源頭阻止 AI 回答

在 Google 上，**始終開啟“網頁”分頁**會開啟 Google 的純連結清單，沒有 AI，也沒有面板。在結果上方選擇**全部**可以看到平常的頁面。
