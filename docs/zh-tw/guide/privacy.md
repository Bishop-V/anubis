# 隱私與許可權

::: warning 翻譯
這是 Anubis 隱私政策頁面的機器翻譯。如果譯文與[英文版](../../guide/privacy.md)不一致，以英文版為準。
:::

Anubis 沒有由開發者運營的伺服器。它在你的瀏覽器中讀取搜尋結果和目前分頁的地址，以應用你的選擇；它不會把這些瀏覽資料傳送給開發者。你的設定儲存在你的瀏覽器中，除非你連接自己的儲存伺服器，在瀏覽器之間同步。

## Anubis 如何使用資料

Anubis 只會把透過瀏覽器許可權獲取的資訊用於面向使用者的功能：把你的排名和標籤應用到搜尋結果上，在彈出視窗中顯示目前網站的設定，下載你訂閱的清單，以及同步到你連接的 WebDAV 伺服器。它不會把這些資訊傳送給開發者，也不會把它們用於廣告。Anubis 沒有自己的同步伺服器。

這種使用符合 Chrome 應用商店使用者資料政策，包括其中的“有限使用”要求。

## 儲存了什麼，儲存在哪裡

- **你的清單、設定、標籤選擇和訂閱**儲存在瀏覽器的同步儲存中。如果你已登入瀏覽器（Firefox 或 Google 賬號）並開啟了同步，瀏覽器會把它們複製到你的其他電腦上。Anubis 從不會看到它們。如果你的清單對同步儲存來說太大，它只會保留在這臺電腦上。參見[在多臺電腦間同步](./sync.md)。
- **同步伺服器的地址和登入資訊**，如果你連接了伺服器以便在瀏覽器之間同步，只儲存在那個瀏覽器中，絕不儲存在瀏覽器同步中。Anubis 會把登入資訊傳送到該伺服器用於登入；它不屬於同步檔案。如果你啟用了端到端加密，它的密碼短語也只儲存在那個瀏覽器中，以便自動同步能對檔案進行解密和加密。
- **已下載的清單**只儲存在這臺電腦上，在其他地方會重新下載。

## Anubis 會連接什麼

只有這些：

- **你訂閱的清單**，連接到它們的託管位置，每天檢查一次新版本，清單有要求時則更少（Anubis 自己的清單：每週一次）。這從你安裝 Anubis 時開始，因為它會為你訂閱託管在其 GitHub 儲存庫中的七個清單：五個是它自己的，兩個是它根據其他專案的資料生成的。你可以在**設定 → 清單**中關閉它們。
- **GitHub 上的清單目錄**，在你開啟**設定 → 清單**時，以便**更多清單**顯示最新的清單。
- **你所在的搜尋引擎**，用於[載入更多結果](./more-results.md)，它會像“Next”連結那樣載入它的下一頁。如果搜尋引擎發來一個沒有結果的頁面，Anubis 會在你看不見的地方再開啟該頁面一次，這等同於你自己開啟它。
- **你為在瀏覽器之間同步而連接的 WebDAV 伺服器**，如果你這樣做了。Anubis 會把你排過名的網站、設定、標籤選擇和訂閱傳送到你提供的 HTTPS 地址，不會發往其他任何地方。新連接預設開啟端到端加密：啟用後，伺服器收到的是它無法讀取的加密檔案。你可以在連接時關閉它；已有的未加密連接在你啟用之前會保持未加密。沒有加密時，伺服器運營者可以讀取該檔案。參見[在瀏覽器之間](./sync.md)。
- **GitHub 上 Anubis 的問題追蹤器**，在你選擇**報告問題**時。這會在新分頁中開啟一個新的 issue，其中填好了 Anubis 的版本、你的瀏覽器及其版本，以及你所在的搜尋引擎，而不包含頁面本身的任何內容。除非你自己提交 issue，否則不會傳送任何內容。
- **問題追蹤器**，在你選擇“報告給…”或“推薦給…”時。這會在新分頁中開啟一個頁面，其中有結果的地址（不含 `?` 之後的任何內容，那裡可能帶有你這次存取的細節）和匹配的規則；除非你自己提交 issue，否則不會傳送任何內容。

下載清單和任何其他下載一樣：託管它的網站會看到你的 IP 地址以及請求的是哪個檔案。Anubis 不會隨之傳送其他任何內容：沒有 Cookie，沒有識別符號，也沒有任何關於你的搜尋的資訊。

## 許可權

安裝 Anubis 時，你的瀏覽器會請求：

- **存取搜尋引擎的網站**，這樣 Anubis 才能更改它們的結果頁面。
- **存取本 wiki 的[訂閱頁面](../../subscribe.md)**，這樣訂閱連結才能開啟 Anubis 的設定並填好一個清單。你的瀏覽器會以本 wiki 所在的網站來稱呼它，即 `bishop-v.github.io`。Anubis 在那裡只讀取連結的地址。
- **儲存**，用來儲存你的清單和設定。
- **當你開啟工具列彈出視窗時的目前分頁**（稱為 `activeTab`）。這讓彈出視窗能讀取你所在網站的地址，以便你為它排名。它不會在安裝時顯示警告，並且持續到該分頁轉到另一個頁面為止。

Anubis 不會在任何其他網站上執行。

在你訂閱時，Anubis 還可能請求**讀取某個網站**，也就是託管清單的網站。對於託管在 GitHub 或 gist 之外的任何地方的清單，這都是必需的。連接同步伺服器時，它也會同樣詢問。你可以在瀏覽器的擴充功能設定中收回這兩項許可權。

在受支援的 Firefox 版本中，Anubis 宣告不需要任何資料收集，並且只在你連接同步伺服器時才請求可選的瀏覽活動同意。隨後 Firefox 會詢問 Anubis 是否可以把你的清單傳送到那裡。**斷開連接**會收回這項同意。
