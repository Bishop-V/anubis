# 隱私與許可權

Anubis 沒有伺服器，也不收集任何資料。它在你的瀏覽器中讀取搜尋結果和當前分頁的地址來應用你的選擇，從不把它們傳送給開發者。

## Anubis 如何使用資料

透過瀏覽器許可權獲得的資料只用於 Anubis 的功能：為結果排名和加標籤、在彈出視窗中顯示當前網站、下載你的清單，以及與你連線的 WebDAV 伺服器同步。這些資料從不傳送給開發者，也不用於廣告。

這種使用符合 Chrome Web Store 使用者資料政策，包括其有限使用（Limited Use）要求。

## 儲存了什麼，存在哪裡

- **你的網站、設定、標籤選擇和訂閱：** 存在瀏覽器的同步儲存中，瀏覽器可能會把它們複製到你的其他電腦上。參見 [在多臺電腦間同步](./sync.md)。
- **同步伺服器的地址、登入資訊和密碼短語：** 只存在那個瀏覽器中，從不進入瀏覽器同步或同步檔案。
- **已下載的清單：** 只存在這臺電腦上。

## Anubis 會連線到哪裡

只有這些：

- **你訂閱的清單**，大約每天一次。Anubis 一開始帶有七個託管在 GitHub 上的清單；可以在**設定 → 清單**中關閉。
- **GitHub 上的清單目錄**，當你開啟**設定 → 清單**時。
- **你正在使用的搜尋引擎**，用於 [載入更多結果](./more-results.md)。在 Ecosia 上，這些結果的網站圖示來自 Ecosia 的圖示服務。
- **你的 WebDAV 伺服器**，如果你連線了的話。它會收到你的網站、設定、標籤選擇和訂閱，預設加密。不加密時，伺服器運營者可以讀取它們。
- **問題追蹤器**，當你選擇**報告問題**（預先填好 Anubis 的版本、你的瀏覽器和搜尋引擎）或清單的**建議更改**時。它們在新分頁中開啟，在你自己提交之前不會傳送任何內容。

託管清單的網站能看到你的 IP 地址和請求了哪個檔案，和任何下載一樣。不會傳送其他任何內容。

## 許可權

- **搜尋引擎的網站**，用來修改它們的結果頁面。
- **本 wiki 的 [訂閱頁面](../../subscribe.md)**（`bishop-v.github.io`），讓訂閱連結生效。Anubis 在那裡只讀取連結的地址。
- **儲存**，用於你的網站和設定。
- **開啟彈出視窗時的當前分頁**（`activeTab`），用於讀取網站的地址。

Anubis 不在其他任何網站上執行。只有在你訂閱託管在 GitHub 以外的清單或連線同步伺服器時，它才會請求讀取另一個網站。在 Firefox 中，Anubis 宣告不收集任何必需資料，只在你連線同步伺服器時請求瀏覽活動方面的同意；**斷開連接**會撤回同意。
