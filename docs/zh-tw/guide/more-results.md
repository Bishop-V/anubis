# 載入更多結果

搜尋引擎一次只傳送一頁結果，所以 Anubis 只能對該頁面上已有的內容重新排序。結果上方摘要中的**載入更多結果**會把下一頁併入目前頁面，並把所有結果放在一起排名。你釘選的、只出現在第 3 頁的網站，點選兩次後就會升到最前面。在手機上，它位於摘要的**詳情**下。

來自後面頁面的結果，會在標題下方用一個小小的空心標記註明“來自第 2 頁”等。它們緊接在最後一個結果之後，所以搜尋引擎自己的頁碼連結仍留在底部。

## 自動載入

**設定 → 外觀 → 自動載入更多結果**會在每次搜尋中載入你輸入的額外頁數，從 0（關閉）到 20。預設是關閉的。每個額外頁面都是對搜尋引擎的又一次請求，會使搜尋多花大約一秒。如果請求過多，搜尋引擎可能會顯示驗證碼或限速，而且大多數引擎在 20 頁之前就不再傳送頁面。設定裡會說明你輸入的數量要付出什麼代價。它會在搜尋引擎自己的“Next”連結或“More results”按鈕出現在頁面底部之後開始，摘要中的按鈕從那時起也會顯示。

## 工作原理

- **DuckDuckGo：** Anubis 會點選 DuckDuckGo 自己的“More results”按鈕。
- **Google、Bing 和 Yahoo：** Anubis 在後臺跟隨頁面的“Next”連結，並把結果新增到目前頁面。
- **Brave Search 和 Ecosia：** Anubis 用頁面自己的連結所用的方式請求下一頁。

請求只會傳送給你所在的搜尋引擎，頁面逐頁載入，每頁之間有短暫的停頓。如果搜尋引擎發來一個沒有結果的頁面，通常是因為它想讓你確認自己不是機器人，Anubis 會再試一次：它在你看不見的地方開啟那個頁面，就像你自己開啟一樣，然後再把它關掉。

## 何時停止

當某個頁面沒有到來時，摘要會在它的第一行下方說明原因，例如“Bing 沒有為第 3 頁傳送任何結果”，**開啟第 3 頁**會在新分頁中開啟該頁面，讓你看到搜尋引擎傳送了什麼。如果它要求你確認自己不是機器人，請在那裡完成，然後再次點選**載入更多結果**。要求 Anubis 放慢速度的搜尋引擎，會在短暫等待後再獲得一次嘗試。當搜尋引擎只傳送頁面上已有的結果時，說明沒有更多了，按鈕會消失。Startpage、Kagi、Yandex、Mojeek 以及 DuckDuckGo 的 HTML 版和 Lite 版目前還不支援此功能。
