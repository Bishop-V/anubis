# 載入更多結果

摘要中的**載入更多結果**會把下一頁拉到這一頁上，並一起排名。後面的結果會標上“來自第 2 頁”等。在手機上，它在**詳情**中。

## 自動

**設定 → 外觀 → 自動載入更多結果**會在每次搜尋時多載入最多 20 頁。每頁大約多花一秒，載入太多可能會觸發人機驗證。

## 工作原理

Anubis 會向你正在使用的搜尋引擎請求下一頁，就像它自己的“下一頁”連結一樣。Startpage、Kagi、Yandex、Mojeek 以及 DuckDuckGo HTML 和 Lite 版尚不支援。

## 何時停止

摘要會說明原因，並附上開啟該頁面的連結。沒有更多結果時，按鈕會消失。

## 人機驗證

如果搜尋引擎想確認你不是機器人，請開啟它指出的頁面，透過驗證，然後再次點選**載入更多結果**。Anubis 從不替你作答。Ecosia 經常要求驗證。
