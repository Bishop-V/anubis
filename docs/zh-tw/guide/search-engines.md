# 搜尋引擎

Anubis 適用於這些搜尋引擎的網頁結果。你可以在**設定 → 搜尋引擎**中關閉其中任何一個。

| 搜尋引擎 | 支援情況 | 載入更多結果 | 在真實網站上檢查過 |
| --- | --- | --- | --- |
| Google（每個國家的網域） | 支援 | 是 | 是，結果和清理都檢查過。手機版佈局還沒有。 |
| DuckDuckGo | 支援 | 是 | 是 |
| DuckDuckGo HTML 和 Lite | 支援 | 否 | 是 |
| Bing | 支援 | 是* | 是 |
| Brave Search | 支援 | 是 | 是 |
| Startpage | 支援 | 是 | 是 |
| Ecosia | 支援 | 是* | 是 |
| Kagi | 支援 | 否 | 是 |
| Yahoo | 支援 | 是* | 是 |
| Yandex | 支援 | 是* | 是 |
| Mojeek | 實驗性 | 否 | 尚未 |

在支援還處於實驗階段的 Android 版 Firefox 上，Google、DuckDuckGo 和 Bing 會向手機傳送它們自己的佈局，Anubis 會讀取其中每一種。這三個已在手機上試過；其他搜尋引擎的手機版佈局還沒有。

**支援**表示已在真實網站上試過。**實驗性**表示它遵循其他工具記錄的佈局，但尚未在真實網站上試過，所以有些功能可能無法使用。

\* Bing、Ecosia、Yahoo 和 Yandex 有時會用“確認你不是機器人”的檢查來回應獲取下一頁的請求。載入更多結果隨後會停下來，也不說明原因。如果發生這種情況，請使用搜尋引擎自己的“Next”連結。

主要的網頁結果在所有引擎上都會被稱量。此外：

- **圖片、影片和新聞分頁**在 DuckDuckGo、Bing、Brave Search、Ecosia、Kagi、Startpage 和 Yandex（僅影片）上，以及 Google 的圖片和新聞分頁上會被稱量。Google 的影片分頁像網頁一樣列出結果，所以按網頁結果來稱量。圖片和影片會被加標籤和隱藏，但不會重新排序，所以網格保持原來的形狀。已隱藏的不會留下空缺。這些分頁都還沒有在真實網站上檢查過。
- **不受影響：** Yahoo 和 Mojeek 的分頁、Yandex 的其他分頁，以及所有購物分頁。

## 如何找到結果

搜尋引擎經常改變頁面的外觀，它們使用的內部名稱也會隨之變化。在可能的情況下，Anubis 透過結果的形狀來找到它們：一個標題、圍繞它的連結，以及只包含該結果的最小區塊。小幅的改版不會破壞這種方式。

對於標題不是 heading 元素的引擎，Anubis 使用 [uBlacklist](https://github.com/ublacklist/builtin) 專案持續更新的結果佈局。

## 搜尋引擎出問題時

如果某個引擎上的結果不再有標籤或按鈕，或摘要出現在錯誤的位置，請參閱[疑難解答](./troubleshooting.md)。
