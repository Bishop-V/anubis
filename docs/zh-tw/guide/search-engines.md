# 搜尋引擎

可以在**設定 → 搜尋引擎**中關閉任意搜尋引擎。

| 搜尋引擎 | 支援情況 | 載入更多結果 |
| --- | --- | --- |
| Google | 支援 | 是 |
| DuckDuckGo | 支援 | 是 |
| DuckDuckGo HTML 和 Lite | 支援 | 否 |
| Bing | 支援 | 是* |
| Brave Search | 支援 | 是 |
| Startpage | 支援 | 是 |
| Ecosia | 支援 | 是* |
| Kagi | 支援 | 否 |
| Yahoo | 支援 | 是* |
| Yandex | 支援 | 是* |
| Mojeek | 實驗性 | 是 |

**支援**的搜尋引擎已在真實網站上檢查過；**實驗性**的還沒有。在 Android 版 Firefox 上，Google、DuckDuckGo 和 Bing 可以使用。

\* 這些搜尋引擎有時會在下一頁之前要求 [人機驗證](./more-results.md)。

網頁結果在所有地方都會被稱量。在大多數搜尋引擎上，圖片、影片和新聞分頁中的結果會加標籤和隱藏，但不重新排序。購物分頁保持原樣。

## 如何找到結果

根據它們的形狀（一個標題和它的連結），而不是頁面的類名，所以小的改版不會造成破壞。在這種方法不奏效的地方，Anubis 使用 [uBlacklist](https://github.com/ublacklist/builtin) 的佈局。

參見 [疑難解答](./troubleshooting.md)。
