# 幫助翻譯

::: warning 機器翻譯：請謹慎使用
Anubis 以英文編寫，這是它唯一完整支援的語言。它也有**阿拉伯語、孟加拉語、中文（簡體）、中文（繁體）、法語、德語、印地語、印尼語、義大利語、日語、韓語、巴西葡萄牙語、俄語、西班牙語、土耳其語、烏爾都語和越南語**版本，但這些翻譯是機器完成的，尚無說這些語言的人檢查過。有些詞可能有誤或不清楚，所以請謹慎使用。當你為網站排名或隱藏網站時，結果選單中的**原因**和結果上方的摘要會準確說明發生了什麼；如果某個譯文讓你拿不準，請核對英文。若要用英文檢視 Anubis，請把瀏覽器的語言設為英文。
:::

Anubis 的介面是英文的。它顯示的每個詞都可以翻譯：工具列彈出視窗、設定、歡迎頁面，以及它在搜尋頁面上新增的內容。你的瀏覽器會選擇與自己語言對應的翻譯，翻譯中遺漏的任何內容仍保持英文。在除英文外的任何語言下，設定、歡迎頁面和工具列彈出視窗都會註明這份翻譯出自機器，並附有指向本頁面的連結。

這個 wiki 也有繁體中文版（機器翻譯，尚未經過中文母語者檢查），位於儲存庫的 `docs/zh-tw/` 資料夾中。面向清單發布者和貢獻者的技術頁面，如清單格式、清單目錄、訂閱頁面和實驗記錄，仍為英文。

如果你會說其中一種語言，修正它是最有用的第一件事：見下文。

## 如何翻譯

翻譯是一個資料夾，位於 [Anubis 的儲存庫](https://github.com/Bishop-V/anubis)中的 `locales/<語言>/`，其中有 `messages.json`（採用瀏覽器為每個擴充功能使用的格式）和 `sources.json`（每條訊息翻譯所依據的英文）。在託管翻譯專案啟動之前，請以 pull request 的形式提交：

1. 把 `public/_locales/en/messages.json` 複製到 `locales/<語言>/messages.json`，資料夾以你的語言代碼命名，地區前加一個底線：`de`、`fr`、`pt_BR`、`zh_CN`、`zh_TW`。瀏覽器只會使用[它們認識的代碼](https://developer.chrome.com/docs/extensions/reference/api/i18n#locales)。
2. 翻譯每個 `message`。你可以省去 `description`；在英文中，描述說明文字出現在哪裡，以及每個 `$1` 或 `$2` 代表什麼。
3. 把 `langCode` 設為你的語言代碼，與資料夾的名稱相同。
4. 執行 `node scripts/locales.mjs record <語言>`。它會寫入 `sources.json`，這樣以後英文發生變化時 Anubis 能夠察覺。
5. 提交 pull request。一項檢查會確保每個鍵在英文中都存在，每個佔位符都保留了下來，每條訊息都說明了它依據的是哪條英文。

你不必一次翻譯所有內容：漏掉一條訊息，它就會顯示為英文。

### 修正機器翻譯

修改 `locales/<語言>/messages.json` 中的 `message`，並在 pull request 中說明你會說這種語言。當你通讀完整種語言後，請更改上表中的“尚未”。`node scripts/locales.mjs status` 會列出英文在翻譯之後發生了變化的訊息；請逐條重新翻譯，然後對它執行 `node scripts/locales.mjs record <語言> <鍵>`。

## 需要保留的內容

- **佔位符。** `$1`、`$2` 等會被填入網站、數字或名稱。請保留每一個，順序按你的語言需要而定。不是佔位符的美元符號要寫成 `$$`。
- **計數。** 以 `_one` 和 `_other` 結尾的訊息是計數的各種形式：“1 個清單”“2 個清單”。請新增你的語言所用的形式，命名遵循 [Unicode 的複數規則](https://www.unicode.org/cldr/charts/latest/supplemental/language_plural_rules.html)：`_zero`、`_one`、`_two`、`_few`、`_many` 和 `_other`。中文只有 `_other`。
- **名稱。** Anubis、搜尋引擎、瀏覽器和其他專案（uBlacklist、HOHSER、Brave Goggles）保留它們的名稱。當訊息提到某個搜尋引擎頁面的某個部分，如 Google 的“AI Overview”或“People also ask”時，請使用該搜尋引擎在你的語言中顯示的名稱。
- **排名所用的詞。** 在 Anubis 中，網站的排名到處都是隱藏、降低、正常、提升或釘選。請為每一個選定一個詞，並始終使用它。對於詞較長的語言，請在其中加入軟連字元（U+00AD），這樣結果選單中那一排排名就能在該斷開的地方斷開。

## 保持英文的內容

- **發給清單維護者的報告和推薦。** 當你報告某個清單的錯誤或向它推薦網站時，Anubis 填好的 issue 是英文的，因為清單的維護者未必讀得懂你的語言。
- **清單檔案。** 你自己的清單（按 Anubis 建立的樣子），以及你訂閱的清單，都由它們的作者編寫。
- **wiki 的技術頁面和商店頁面介紹。** 它們另行翻譯。

## 檢查你的翻譯

用你的檔案構建 Anubis（`npm run build`；參見 [`DEVELOPMENT.md`](https://github.com/Bishop-V/anubis/blob/main/DEVELOPMENT.md)），並在設為你的語言的瀏覽器中載入它；`ANUBIS_LANG=<程式碼> node e2e/run.mjs responsive` 會在手機寬度下檢查其中的設定。在 Firefox 中，請在“設定 → 常規 → 語言”下新增你的語言；在 Chrome 中，請在“設定 → 語言”下選擇它，或用 `--lang=<程式碼>` 啟動 Chrome。請在窄寬度下檢視彈出視窗和設定，因為較長的詞可能會把按鈕擠到第二行。

阿拉伯語和烏爾都語是從右向左書寫的：Anubis 的頁面以及它新增到搜尋頁面上的內容會隨之翻轉。請同樣在窄寬度下檢查從右向左書寫的語言。
