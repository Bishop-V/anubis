# Loading more results

**Load more results** in the summary pulls the next page onto this one and ranks everything together. Later results are marked "From page 2" and so on. On a phone, it's under **Details**.

## Automatically

**Settings → Results → Load more results** loads extra pages on every search: 3 by default, up to 20. Set it to 0 to load more only when you ask. Each page adds about a second, and too many can bring a robot check.

## How it works

Anubis asks the engine you're on for its next page, as its own "Next" link would. It can't yet on Kagi, on DuckDuckGo's HTML and Lite pages, or on Google on a phone. See [Search engines](./search-engines.md).

## When it stops

The summary says why, with a link to open that page. When there are no more results, the button goes away.

## Robot checks

If the engine wants to check you're not a robot, open the page it names, pass the check, and press **Load more results** again. Anubis never answers it for you. Ecosia asks often.
