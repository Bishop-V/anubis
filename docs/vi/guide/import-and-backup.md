# Chuyển từ công cụ khác

## Nhập trang web

**Cài đặt → Sao lưu → Nhập trang web** nhận quy tắc của bạn: dán chúng hoặc chọn tệp, rồi nhấn **Nhập**.

| Từ | Bạn nhận được |
| --- | --- |
| **uBlacklist** | Trang bị chặn sẽ bị ẩn; tô sáng thành nhãn. |
| **HOHSER** | Ẩn vẫn ẩn, ẩn một phần thành Hạ, tô sáng thành nhãn. |
| **Brave Goggle** | `discard` thành Ẩn, `boost` thành Nâng, `downrank` thành Hạ. |
| **Danh sách tên miền** | Mọi tên miền bị ẩn. |

Quy tắc cần nhiều hơn tên trang web sẽ bị bỏ qua. Với danh sách người khác xuất bản, hãy [đăng ký](./lists.md) để nhận cập nhật của họ.

## Sao lưu

**Xuất bản sao lưu** lưu mọi thứ vào một tệp, và **Khôi phục bản sao lưu** nạp nó trên bất kỳ trình duyệt nào. **Đặt lại cài đặt** trở về mặc định nhưng giữ trang web của bạn.

## Chia sẻ danh sách của bạn

**Tải danh sách của tôi xuống** lưu trang web của bạn thành tệp văn bản, sẵn sàng để [xuất bản](./publish-a-list.md).
